How preview jobs use this

Engine first, then a hand pass for the business.

  1. Write the spec from their own pages, pick the theme, and set palette from their logo colors when they have a clear brand color.
  2. Render with engine/render_concept.py. Logos, photos and fonts land in the preview's own folder.
  3. Refine for the business: wording, order and kicker in the spec; anything visual in a refine.css beside the page, which every re-render keeps.
  4. Run engine/check_preview.py, look at both screenshots, fix, and publish.
